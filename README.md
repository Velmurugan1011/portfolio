# Velmurugan — Developer Portfolio

My personal portfolio website: a responsive single-page site that introduces who I am, my experience, my skills and the projects I've worked on.

## Sections

- **About** — introduction, experience and education, with a downloadable CV
- **Experience** — frontend and backend skills
- **Projects** — projects I've worked on (Factorydx3, Renogeo, Rhiphone)
- **Contact** — ways to reach me

## Run Locally

```bash
git clone https://github.com/Velmurugan1011/portfolio.git
cd portfolio
# open index.html in your browser
```
